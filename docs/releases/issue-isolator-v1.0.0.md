# Issue Isolator v1.0.0

First public release candidate.

## Included

- one-active-symptom-at-a-time debugging
- `PROVEN`, `SUSPECTED`, `CONFLICTING`, and `UNPROVEN` evidence labels
- boundary-first isolation across UI, API, service, process, network, container, data, deployment, and runtime layers
- explicit parking of secondary symptoms
- one discriminating read-only or low-risk next test by default
- result interpretation before remediation
- no helper scripts, network access, or binary payloads
